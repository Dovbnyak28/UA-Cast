# UA-Cast — коротке вікно плеєра й вибір доріжок, 2026-11-10

## Підтверджені проблеми

1. **Локальне відео, 640×240dp, системний шрифт 200%.** Header з двома рядками назви,
   таймлайн і окремий рядок «±10 с» займали місце нижніх контролерів. Кнопка відтворення
   переставала бути видимою. Шлях: FullscreenPlayerContent → PlayerControlsOverlay →
   FilePlaybackProgress → PlayerOverlayFooter. Це проблема компонування; тест не свідчить
   про зупинку Media3 або зміну playback state.
2. **Сусідні короткі назви каналів.** Text-chip обмежував лише максимальну ширину.
   Автоматично розширені до 48dp touch bounds сусідніх «1» і «2» перетиналися.
   У тестовому xhdpi-вікні перекриття становило 5 фізичних пікселів. Натискання біля краю
   могло потрапити до сусіднього каналу.

Ці два випадки відтворені до зміни production-коду: 8 failures у 12 перевірках
(4 локалі; file layout і touch-target separation). Чотири live-layout перевірки вже проходили.
Збережено XML та знімки початкового стану в reproduction/.

Окреме UX-покращення: «Субтитри вимкнено» мало selected semantics, але не мало видимого
радіоіндикатора, на відміну від інших доріжок. Це не помилка вибору доріжки в Media3.

## Виправлення

- Для широкого вікна від 600dp завширшки й нижче 320dp використовується компактне оформлення
  overlay: однорядкова назва, менші вертикальні відступи, іконка інших TV з попереднім
  accessibility-описом. Додаткові badges і preview-полиця в цьому режимі не відображаються;
  відомості про потік і список каналів доступні в меню «Ще».
- «−10 с» і «+10 с» у компактному режимі розміщені між часовими позначками над повзунком.
  У звичайному плеєрі залишається попередня розкладка. Seek callbacks, enabled-стан
  і правила обмеження позиції не змінені; обидві розкладки використовують один helper.
- Чипи каналів мають мінімум 48×48dp та окремі touch bounds. Збережено оригінальний
  IndexedChannel/index, callback вибору й стабільні ключі списку.
- Для доріжок і вимкнення субтитрів використано один selectable рядок з радіоіндикатором,
  підсвіченням вибраного стану та читабельним основним текстом. RadioButton не має окремого
  onClick; натискання обробляє лише батьківський рядок. Список має selectableGroup.

LocalCompactPlayerControls — незмінний CompositionLocal представлення. Його provider
обмежений overlay; inline і окремий TV-плеєр залишаються у звичайному режимі.
VideoSurface, Media3, ViewModel, Cast/DLNA та їхні lifecycle-власники не змінені.
Нових залежностей, растрових ресурсів, blur або безперервної анімації не додано.

## Перевірки

- 12 нових geometry/interaction перевірок: live і file у 640×240dp зі шрифтом 200%,
  touch bounds коротких каналів; українська, англійська, іспанська та російська.
- 2 нові перевірки доріжок: один callback на натискання, переключення off ↔ track,
  збереження TrackGroup, фактичний fontScale 2.0 і довгі назви/метадані без обрізання.
- Повний JVM/screenshot gate: app 2928 + core 133 + decoder 5 = **3066 PASS**,
  0 failures/errors/skips. Перевіряються також звичайні розміри плеєра, seeking,
  автоховання контролерів, збереження VideoSurface й наявні діалоги.
- Lint Debug/Release/Play: 0 errors, 0 warnings; по 2 інформаційні hints інструментарію.
- Detekt app/core: 0 findings. Baseline порожній. Архітектурні межі, Cast icon placement
  і правило кольорів пройшли.
- Android API 36: **30 PASS**, 0 failures/skips, 111.359 s. Це 17 UI-сценаріїв,
  8 локального відео, 1 fullscreen/реальне декодування/збереження native views,
  4 повернення TV-фокуса. Прогін виконано окремо від Gradle-навантаження.
- Crash buffer власного AVD: 0 bytes. Початкові дані debug-пакета відновлено;
  контрольні суми 45 файлів звірено. Зафіксовано 1419 файлів джерел/еталонів,
  після тестів розбіжностей немає. Результати зібрані у verified-results.json.

Скриншоти навмисно оновлені лише для змінених поверхонь: звичайної preview-полиці,
коротких вікон і нового вибору доріжок. Візуальні еталони переглянуті вручну.

## Межі висновків

640×240dp — окремий стрес-сценарій малого вікна, а не вимір продуктивності пристрою.
FPS/heap не вимірювалися. Попередній fullscreen performance budget і поодинокий тайм-аут
з UI_DETAILS_2026-11-10.md не оголошуються виправленими цими UI-змінами.
Фізичний телевізор і телефони не використовуються. CI, GitHub-публікація й production
release не виконуються; APK призначений для окремої debug-перевірки.
Після збереження результатів завершено тільки власний AVD ua-cast-branding;
комп’ютер і фізичні пристрої не вимикалися.
