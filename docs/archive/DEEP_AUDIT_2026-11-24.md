## 2. Що треба поправити

### 2.1 Важливо (до релізу)

1. **Автоматичний PiP не працює на Android 8–11.** Автовхід реалізований лише через
   `setAutoEnterEnabled` (API 31+, `PlayerGestureLayer.kt`, `PlayerScreenState.kt`). На API 26–30
   немає запасного виклику з `onUserLeaveHint`, тож «Додому» під час повноекранного відтворення
   просто ставить відео на паузу. Перевірено на Mi A2 (Android 11). Бюджетні Xiaomi/Samsung на
   Android 10–11 — значна частка аудиторії. Виправлення: у `MainActivity.onUserLeaveHint()` для
   API 26–30 входити в PiP за тим самим правилом `autoEnterPip`.
2. **Тестові HTTP-сервери можуть валити процес інструментальних тестів.** `serve()` у фікстурах
   `ProxyServerInstrumentedTest`, `ProxyFlattenInstrumentedTest`, `DlnaClientInstrumentedTest` не
   ловить `IOException`; обрив з'єднання з боку проксі посеред відповіді кидає виключення у фоновому
   потоці, і Android завершує весь процес («Process crashed»). `ProxyRemuxInstrumentedTest` уже
   захищений. PR #14 закрив лише гонку при закритті пулу. Виправлення: обгорнути `serve()` у
   `try { … } catch (_: IOException) {}` на місці виклику.
3. **`device-budgets` падає випадково на `enterFullscreen`.** p95 часу кадру на тому самому коді —
   60–120 мс при межі 100 мс (провали на #8 і #14). Причина за трасами perfetto: у вимірюване вікно
   потрапляє поворот екрана. Виправлення: виконувати поворот у setup і міряти лише вхід у повний
   екран, а не послаблювати межу.
4. **CI регулярно отримує HTTP 429 від Maven Central.** За два дні — щонайменше п'ять провалів
   (lint, декодер, benchmark, інструментальні на API 24/36), щоразу на завантаженні залежностей.
   Кеш Gradle для гілок уже пишеться (`cache-read-only: false`), але ~10 паралельних задач нового
   коміту разом качають те, чого в кеші ще немає. Варіанти: одна задача, що прогріває кеш перед
   рештою, або повтор кроку при 429.

### 2.2 Бажано

5. **Залежності відстають** (lint, лише підказки): Play Billing 8.0 → 9.1, Media3 1.10.1 → 1.11.1,
   Cast framework 22.3.1 → 23.0, Kotlin 2.4.0 → 2.4.21, Compose BOM 2026.06 → 2026.11,
   OkHttp 5.4 → 5.5.1, Lifecycle 2.10 → 2.11.1, Gradle 8.14.4 → 8.14.8; AGP 8.13 → 9.5 — мажорне,
   окремою задачею. Billing 8 ще підтримується, але перехід краще зробити до наступного релізу.
6. **У ландшафті на телефоні панель керування повного екрана закриває близько половини відео**
   (висота ~360 dp). Можна стиснути нижню панель або ховати смугу каналів, коли висоти мало.
7. **Кроки CI з хибними назвами.** У `android-ci.yml` завантаження native-бібліотек підписане як
   «Assemble debug», «Android lint», «Assemble release», «Enable KVM» — логи вводять в оману.
   Виправлено в цьому PR («Download verified native libraries»).
8. **Застарілий пункт у `docs/STATUS.md`**: тести на API 36 позначені як «падають з базового
   коміту», хоча зараз стабільно зелені. Виправлено в цьому PR.
9. **На тестовому Mi A2 лишились старі тестові пакети** `com.uacastplayer.debug.test`,
   `com.uacastplayer.debug.minified.test`, `com.uacastplayer.baselineprofile` (від збірок до
   перейменування). Не заважають, але їх можна видалити.

### 2.3 Власнику (не код)

10. Play Console: декларація foreground service типу `mediaPlayback`; у Data safety — дозволений
    незашифрований HTTP для IPTV-потоків (`network_security_config.xml`); нова адреса політики.
11. Решта кроків із фінального аудиту: схвалення продажів (`commerce`), секрети `ZORIK_*`, internal
    testing і чекліст покупок, історичний GPL, патенти кодеків, перевірка назви.
12. Реальне обладнання так і не перевірене: Chromecast, DLNA-телевізор, Android TV з D-pad, Samsung.

## 3. Що перевірено й у порядку

- Маніфест: назовні доступна лише `MainActivity`; провайдери не експортовані; резервне копіювання
  вимкнене (`allowBackup=false`, `data_extraction_rules` виключають усе); дозволи play-збірки
  мінімальні (з бібліотек додається лише `BILLING`).
- `VIEW content://… video/*` приймає тільки `content`-адреси; помилки відкриття обробляє
  `LocalVideoOpenViewModel`.
- Native-бібліотеки зібрані з `max-page-size=16384`, вирівнювання на 16 КБ перевіряє
  `prepare-software-decoder.py`.
- Edge-to-edge і predictive back увімкнені явно (`enableEdgeToEdge`, `enableOnBackInvokedCallback`).
- Lint: жодних попереджень, лише підказки про версії; базовий список detekt порожній; у робочому
  коді немає TODO/FIXME; `@Suppress` поодинокі й пояснені.
- Технічний борг без змін: `CastSessionRepository` (823), `PlayerViewModel` (813), `ProxyServer`
  (783) рядків.
