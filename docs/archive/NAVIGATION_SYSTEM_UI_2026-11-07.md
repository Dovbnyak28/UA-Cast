# Навігація й системне оформлення UA-Cast

Реалізація: 2026-11-07. Фінальна перевірка: 2026-11-08.
Наступний етап після `UI_USABILITY_IMPLEMENTATION_2026-11-07.md`.

## Реалізовано

- Вкладки називають розділ: Головна, Канали, Обране, Налашт. На великому шрифті
  зміст зберігається; навігація переходить у два ряди. Чотири локалі перевіряються
  на ширині 320dp зі шрифтом 200%. При 150% висота двох рядів не менша за 104dp.
- Відвідування вкладок більше не створює історію повернення. З кореневого розділу
  Back веде на Головну, з Головної — на вихід. Повторний вибір вкладки не дублює її.
  Старий збережений шлях нормалізується; невідомий ID безпечно відкриває Головну.
- Налаштування показують один контекстний заголовок зі стрілкою повернення.
  Загальний заголовок Settings над назвою підсторінки прибрано. Банери оновлення
  й завантаження залишаються в кореневій панелі, системний відступ застосовується один раз.
- Нижня панель пласка, без зовнішніх відступів, градієнтної підсвітки й press-scale.
  Мініплеєр прилягає до неї; відступи обчислюються зі спільних метрик. Його зображення,
  play/pause і явна зупинка × збережені. Немає другого call site PlayerHost або нового ExoPlayer.
- Виправлено пріоритет Back: згорнутий плеєр більше не перехоплює повернення зі
  сторінок налаштувань. Розгорнутий плеєр, як раніше, згортається. Під час навігації
  мініплеєр продовжує існувати; явна зупинка виконується через × або вихід із застосунку.
- Додано вибір «Як у системі» на телефоні: Daylight у світлому режимі Android,
  Midnight у темному. Зберігається ID SYSTEM, а не поточна похідна палітра.
  Плеєр залишається темним; перемикання палітри не змінює власника композиції плеєра.
  Існуючий Cinema default не змінений. TV зберігає темне оформлення.
- Під час перевірки повного екрана знайдено чорну підказку про формати відео на
  темному фоні. `OpenLocalVideoButton` тепер задає `labelSecondary` явно. Новий тест
  відтворив чорний колір до виправлення та перевіряє фактичний колір тексту в усіх
  темах після нього. Додані окремі зображення компонента з активним document host
  у Cinema й Daylight: попередня ізольована Home-фікстура цього блоку не показувала.

Фінальний прогін поточного коду успішний:

| Core | 133 тести, 0 failures/errors/skipped |
| Native UI / локальне відео / lifecycle, Android 16 API 36 | 38 тестів, 0 помилок і пропусків; 179,483 с |
| Lint Debug / Play | 0 errors, 0 warnings; по 2 інформаційні hints |
| Detekt / архітектурні межі | Успішно; baseline порожній |
| Приватні debug-дані емулятора | 45 файлів відновлено з перевіркою хешів |
| Фінальний crash-буфер | Порожній |

1347 файлів коду, тестів, еталонів і конфігурації звірено з хешами після прогонів.
Скриншот повного Home повторно переглянуто: підказка про формати читається на темному
фоні, мініплеєр прилягає до навігації. Перевірені еталони звичайної панелі й 200% шрифту.

Цільові перевірки охоплюють 30 швидких виборів вкладок, старі збережені шляхи,
довгі локалізовані підписи, 48dp кнопки заголовка та зміну системної теми без повторного
створення власника плеєра. Нові native-сценарії перевіряють Back з активним мініплеєром,
відсутність дубльованого заголовка, суміжність нижніх панелей та відновлення SYSTEM після
повторного створення Activity. Геометричні й поведінкові перевірки не замінені лише скриншотами.

Еталони змінюються тільки для навмисно перероблених компонентів. Попередні файли
збережено в локальному каталозі `build/navigation-2026-11-07/before/`.

Один проміжний повний прогін завершився таймаутом у наявному
`ProxyManifestLeaseTest`: отримані 172 байти заголовків, очікування наступних байтів
перевищило незмінений ліміт 5 секунд. Збережені стек і JUnit XML. Окремий повтор
усіх чотирьох тестів цього класу пройшов; причина одиничного збою поки не доведена.
Повний повтор із GC/safepoint діагностикою пройшов усі 2891 тести; таймаут не повторився.
У повторі найбільша safepoint-пауза становила 131,09 мс. Це не доводить причину
первинного збою: GC-діагностики того запуску немає. Одиничний таймаут залишається
задокументованим нерозслідуваним випадком. Код проксі й часові межі не змінювалися,
жоден тест через цей збій не виключено.

## Межі

Фізичні Xiaomi TV і телефони не використовуються. Окрема зміна відновлення D-pad фокуса
на останньому каналі TV до цього етапу не входить. Chromecast/DLNA механізми не змінені.
Попереднє перевищення fullscreen performance budget не оголошується усунутим:
повторний Macrobenchmark у цьому етапі не виконується. Потрібна окрема перевірка на
сталому CI runner і фізичному пристрої. Нового production-релізу або публікації GitHub немає.
Власний тестовий емулятор завершено після відновлення даних; комп’ютер не вимикався.
