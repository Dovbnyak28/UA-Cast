## Текст сторінки

Назва: **UA Cast Player**.

Короткий опис українською: «Ваші канали й відеофайли на телефоні та Android TV».

Короткий опис іспанською: «Tus canales y archivos de vídeo en el móvil y Android TV».

Основний опис:

> UA Cast Player відтворює ваші власні плейлисти й вибрані відеофайли.
> Канали, підписки та права на контент не входять до застосунку. Додайте джерело,
> на використання якого маєте дозвіл. Доступні обране, пошук, програма передач
> із налаштованого джерела, Android TV і керування UA-Cast із телефона.
> Сумісне відео можна передавати на Google Cast або DLNA-приймачі.
> Підтримка конкретного потоку залежить від формату, пристрою, мережі й обмежень
> провайдера. На телевізорі та в телефоні використовується той самий особистий
> набір джерел; застосунок не надає власного каталогу телеканалів.

Не обіцяти «всі формати», гарантоване відтворення на кожному Hisense,
безумовну конфіденційність сторонніх SDK або доступ до платних каналів.
Не рекламувати покупки, поки checkout вимкнений.

## Матриця для Data safety

Це вихідні факти для форми, не автоматично надіслана декларація. Google вимагає
врахувати сторонні SDK; винятки для анонімних даних і передачі за дією користувача
потрібно застосовувати за визначеннями форми до фактичної версії SDK.

| Потік | Факт у застосунку | Що звірити у формі |
| --- | --- | --- |
| Джерела, обране, EPG, кеш | Зберігаються локально | Локальне зберігання саме по собі не передача розробнику |
| Провайдери/пак іконок | HTTP(S)-запити за налаштуваннями користувача | Одержувачі, IP/мережеві метадані, credentials у власній URL |
| Cast sender SDK 22.3.1 | Інтегрований Google SDK | SDK disclosure застосовується до latest SDK; перевірити придатність до цієї версії |
| DLNA/relay/пульт | URL, метадані й медіа передаються вибраному приймачу | Передача за дією користувача; можливий HTTP без шифрування |
| GitHub update check | Мережевий запит/завантаження | Play variant прибирає sideload updater; перевірити саме Play manifest/код |
| Support | Локальний звіт, ручне надсилання через інший застосунок | Не автоматичний crash upload; користувач може включити особисті дані |
| Backup | Шифрований файл у вибраному document provider | Хмарний provider може отримувати файл за вибором користувача |
| Billing | Код інтеграції є, продажі вимкнені | Не декларувати майбутню поведінку як поточну; повторити перед активацією |
| Реклама/аналітика розробника | Власний analytics backend і рекламний SDK відсутні | Не плутати з даними стороннього Cast SDK |

Не ставити загальне «всі передачі зашифровані», не врахувавши HTTP-провайдерів
і локальних приймачів. Не ставити «даних немає» лише через відсутність бекенду.

## Зображення та остаточна перевірка

Для listing використовувати тільки власні/згенеровані матеріали та синтетичні
канали й відео; не переносити приватні captures або кадри серіалів зі звернень.
Перевірені screenshot goldens тестують UI, але не автоматично стають магазинними
матеріалами. Перед поданням потрібні фінальні captures потрібних розмірів,
content rating, target audience, TV declarations та звірка контакту/identity
з верифікованим акаунтом видавця.
